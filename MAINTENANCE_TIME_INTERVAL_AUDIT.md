# Default maintenance time-interval audit

Audit date: 2026-08-03  
Profile: New Symphony ST 200 / XL20W1-EU and XL20W1-IT  
Profile version: 2026.08.03-ia1

## Result

All 29 active default `intervalMonths` values are explicitly supported by the official owner manual. None was generated by converting kilometres to months.

The former fixed air-filter cleaning and paper-element replacement countdowns remain in the source profile as inactive evidence, so existing records retain their rule identities. They are no longer active defaults: the product now presents a 1,000 km air-filter inspection plus independent condition-based cleaning and replacement actions. The inspection's one-month time interval remains active because it is explicitly printed in the cited combined manual column; it was not inferred from 1,000 km.

The official manual's periodical-maintenance table on PDF page 26 names combined columns `Every 1000KM / 1 Month`, `Every 3000KM / 3 Months`, `Every 6000KM / 6 Months`, and `Every 12000KM / 1 Year`, then says the applicable limit is whichever comes first. A rule receives the paired time only when its row has an action mark in that exact combined column. Transmission oil is separately printed as `Replacement for every 5000KM (5 Months)` in row 13.

An `interpreted` rule confidence means the table's `I` mark was normalized into an inspection action. It does not mean the month value was inferred from distance. The month/year value is still printed in the marked column header.

The validator now emits `unsupported_default_time_interval` whenever an applicable default month value is not present in the rule's cited table row, source text, supporting source, or approved owner-decision text. This check does not apply to a vehicle owner's custom time reminder.

## Non-default user time reminders

Condition-based and no-fixed-interval actions still allow a vehicle owner to add a personal month reminder. Those values are stored as `user_custom`, are labelled as user-created/custom in the UI, and are not presented as manual defaults.
